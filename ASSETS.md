All three photographs are AI-generated illustrative concepts created using the built-in ImageGen tool for this proposal. They do not depict verified Calvin projects. This distinction is visible in the gallery, lightbox, hero caption and FAQ.

The following files are optimised WebP versions of the generated originals. The `-small` versions are 720px wide; the larger versions are 1440px wide. Image processing only resized and encoded the generated assets.
